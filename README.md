## 📚 Concepts Covered

### 1. Binary Tree Basics
- Root, parent, child, leaf, and subtree.
- Left and right child references.
- Empty trees and null nodes.
- Height and depth of a tree.

### 2. Tree Traversal
- **BFS (Breadth-First Search):** Visits nodes level by level.
- **DFS (Depth-First Search):** Explores branches recursively.
- Preorder Traversal: Root → Left → Right.
- Inorder Traversal: Left → Root → Right.
- Postorder Traversal: Left → Right → Root.
- Level Order Traversal: Visits nodes level by level.

### 3. Recursion
- Base cases.
- Recursive calls.
- Processing left and right subtrees.
- Returning results from recursive functions.

### 4. Queue Data Structure
- FIFO (First In, First Out).
- `offer()` to add an element.
- `poll()` to remove an element.
- `isEmpty()` to check whether the queue is empty.
- Using a queue for BFS.

### 5. Tree Comparison
- Comparing node values.
- Checking whether two trees are identical.
- Handling null nodes.
- Checking whether one tree is a subtree of another.

### 6. Tree Construction
- Constructing a tree using preorder and inorder traversals.
- Finding the root from preorder traversal.
- Dividing left and right subtrees using inorder traversal.
- Using a HashMap for efficient index lookup.

### 7. Serialization and Deserialization
- Converting a binary tree into a string.
- Representing null nodes using markers.
- Reconstructing the original tree.
- Preserving the tree structure during conversion.

### 8. Complexity Analysis
- Time complexity: O(n), O(n × m).
- Space complexity: Recursive stack and auxiliary data structures.
- Understanding best, average, and worst-case behavior where applicable.
